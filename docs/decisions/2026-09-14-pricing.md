# Pricing page

## Scope

- Add `/pricing` for the proposed single Website + CMS package.
- Reuse the Home header/footer, cream palette, gold accents, and serif emphasis.
- Add desktop/mobile/footer Pricing links and active navigation state.
- Point shared Home section links to `/#...` so they also work from Pricing.
- Include feature groups, usage disclosure, optional add-ons, FAQ, and CTA.
- CTA opens the existing Home theme gallery. No checkout/payment is simulated.

## Commercial decisions still open

Prior handoff prices and quotas were examples, not approved business terms.
No Rp249,000 price, 10 GB quota, discount, trial, or cancellation promise is published.
The page explicitly says subscriptions are not open yet.
Storage expansion and AI are marked planned; domain registration is separate.
Feature descriptions describe the proposed package, not backend completion.

## Configuration

- `src/data/pricing/plan.ts`: approved billing totals in integer IDR.
- `billingOptions: []`: pre-launch state, no billing selector or invented price.
- One option: its price and period are shown without an unnecessary selector.
- Two options: native monthly/yearly radio controls with live price announcement.
- Yearly `amount` is the full annual bill, never an implied monthly price.
- `src/data/pricing/features.ts`: feature copy, approved quotas, add-on status.
- `src/data/pricing/faq.ts`: FAQ copy and commercial conditions.
- Before launch, finalize prices, quotas, tax treatment and subscription terms;
  update FAQ/add-on availability and connect the actual onboarding/checkout flow.
- Frontend quotas must agree with server-side entitlements and enforcement.

## Implementation

Route and content are server components; only billing selection uses local state.
FAQ uses native details/summary for keyboard support without client JavaScript.
Icons are small inline SVGs. Effects use CSS; no new runtime dependency.
CSS lives in `src/styles/pricing/`, scoped beneath pricing-specific classes.
Layouts adapt at 1000, 700, and 380 px. Reduced motion disables animation.
All added/modified source files stay below 70 lines.
