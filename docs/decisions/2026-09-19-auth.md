# Mangelek account entry

Implemented login, signup, password recovery and reset, plus a server-verified account entry page. Google uses Supabase OAuth; Gmail is usable as an email identity, with no inbox permissions requested. Home's existing login link now resolves, and its desktop/mobile start actions point to signup.

## Design and motion

The layout extends local Manrope typography and Mangelek's existing editor illustration. Desktop pairs a quiet product panel with the form; mobile removes the illustration to keep the task direct. Native fields support password managers, email keyboards and text zoom. The show-password control preserves entered values. Error states focus the invalid field or error summary; pending requests guard against repeated submission.

| Before | After | Why |
| --- | --- | --- |
| Login link had no page | Dedicated account-entry routes | Complete navigation |
| No account flow | Email/password and Google SDK actions | Real provider integration |
| No form feedback | Inline errors, pending states, email confirmation | Make each outcome clear |
| No auth motion system | 160ms press feedback, one 200ms entry transition | Immediate, restrained interaction |
| Placeholder contrast 4.28:1 in first pass | 5.64:1 after finish review | Meet AA text contrast |

Animation and Apple-design principles guide the responsive feedback, interruptibility and restraint. Keyboard focus avoids press transforms; reduced-motion settings disable nonessential transitions. No decorative loops, artificial success, fabricated social proof or payment step is added.
