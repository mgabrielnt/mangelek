# Runbook yang harus diisi setelah runtime dipilih

Deployment staging/production; rollback aplikasi dan publikasi;
migrasi expand-contract; backup dan restore; insiden keamanan;
rotasi rahasia; dead-letter queue dan replay; domain/SSL bermasalah.
Setiap runbook memerlukan prasyarat, langkah, verifikasi, dan penanggung jawab.
Belum ada perintah operasional yang aman dianggap siap produksi.
