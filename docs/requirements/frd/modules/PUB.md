Fitur utama: Release statis, validasi, rollback, render edge, perilaku per status, HTTPS

Ringkas: 13 kebutuhan (9 Must), 12 kriteria penerimaan, 12 test case.

## Kriteria penerimaan

| ID | Kriteria penerimaan | Kebutuhan | Prioritas | Test case |
| --- | --- | --- | --- | --- |
| AC-PUB-01 | Diberikan draf tersimpan, ketika Terbitkan ditekan, maka perubahan tayang ≤ 60 detik dari release baru ber-object\_prefix unik, dan release sebelumnya tetap di riwayat 20 terakhir (D-02). | PUB-001, PUB-004 | Must | TC-PUB-001 |
| AC-PUB-02 | Diberikan revisi tanpa beranda, aset milik site lain, atau tautan navigasi rusak, ketika diterbitkan, maka E-PUBLISH-INVALID berisi daftar lokasi masalah dan tidak ada release dibuat. | PUB-002 | Must | TC-PUB-002 |
| AC-PUB-03 | Diberikan galat buatan di langkah build, validasi, dan aktivasi, ketika terbit berjalan, maka release failed, active\_release\_id tidak berubah, dan pelanggan melihat “Terbit gagal, versi sebelumnya tetap tayang”. | PUB-003 | Must | TC-PUB-003 |
| AC-PUB-04 | Diberikan release ready lama, ketika dipulihkan, maka tayang ≤ 60 detik tanpa build ulang, dihitung ke kuota terbit, dan tercatat di audit. | PUB-005 | Must | TC-PUB-004 |
| AC-PUB-05 | Diberikan release lama, ketika disalin ke draf, maka revisi draf baru berisi dokumen release itu tanpa mengembalikan item CMS. | PUB-006 | Should | TC-PUB-005 |
| AC-PUB-06 | Diberikan host tak dikenal, host bukan kanonik, dan host kanonik, ketika diminta ke Worker Sites, maka berturut-turut 404 umum, 301, dan halaman dari release aktif dengan kunci cache memuat site\_id dan release\_id. | PUB-007 | Must | TC-PUB-006 |
| AC-PUB-07 | Diberikan simulasi tanggal grace, suspended, provisioning, dan deleted, ketika website dibuka, maka berturut-turut normal, 503 + noindex “Website ini sedang tidak aktif”, 503 “Website sedang disiapkan”, dan 404. | PUB-008 | Must | TC-PUB-007 |
| AC-PUB-08 | Diberikan permintaan http://, ketika dibuka, maka 301 ke https:// dengan HSTS max-age 6 bulan tanpa preload. | PUB-009 | Must | TC-PUB-008 |
| AC-PUB-09 | Diberikan teks unik di draf yang belum terbit, ketika host publik, cache, dan sitemap dicari, maka teks itu tidak ditemukan; pratinjau membawa Cache-Control private, no-store dan X-Robots-Tag noindex. | PUB-010 | Must | TC-PUB-009 |
| AC-PUB-10 | Diberikan 30 terbit atau rollback dalam sehari, ketika terbit ke-31 diminta, maka E-QUOTA-EXCEEDED dengan waktu reset. | PUB-011 | Should | TC-PUB-010 |
| AC-PUB-11 | Diberikan dua terbit hampir bersamaan, ketika build lama selesai belakangan, maka release dari permintaan terakhir yang aktif dan build lama tidak menimpa (fencing). | PUB-001 | Must | TC-PUB-011 |
| AC-PUB-12 | Diberikan Hentikan Penayangan dan path tak ada, ketika dibuka, maka website menampilkan halaman tidak aktif sampai terbit ulang, dan 404 mengikuti palet serta font website. | PUB-012, PUB-013 | Could | TC-PUB-012 |
