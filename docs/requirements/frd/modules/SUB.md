## Kriteria penerimaan

| ID | Kriteria penerimaan | Kebutuhan | Prioritas | Test case |
| --- | --- | --- | --- | --- |
| AC-SUB-01 | Diberikan transisi yang tidak ada di tabel 5.5 (misalnya expired → grace), ketika dipicu, maka ditolak dan tercatat di audit. | SUB-001 | Must | TC-SUB-001 |
| AC-SUB-02 | Diberikan notifikasi lunas ganda untuk satu baris langganan, ketika diproses paralel, maka hanya satu subscription\_periods tercipta dan rentang periode tidak tumpang tindih. | SUB-002 | Must | TC-SUB-002 |
| AC-SUB-03 | Diberikan tabel uji tanggal (31 Jan + 1 bulan = 28 Feb 2027; 29 Feb 2028 + 12 bulan = 28 Feb 2029; bayar sebelum H mulai dari H; bayar setelah H mulai dari paid\_at), ketika fungsi dijalankan, maka semua hasil cocok dengan cakupan cabang 100%. | SUB-003 | Must | TC-SUB-003 |
| AC-SUB-04 | Diberikan dua website dengan langganan aktif di satu akun, ketika jam mencapai H-7 dan pelanggan menekan Perpanjang Sekarang, maka hanya satu order perpanjangan per siklus per website, harga mengikuti perubahan terjadwal bila ada, dan pelanggan yang berhenti tidak menerima order. | SUB-004 | Must | TC-SUB-004 |
| AC-SUB-05 | Diberikan H lewat tanpa pembayaran, ketika H+1 sampai H+7 disimulasikan, maka website tayang normal, editor dan unggah hanya-baca, dan spanduk hitung mundur tampil. | SUB-005 | Must | TC-SUB-005 |
| AC-SUB-06 | Diberikan grace berakhir, ketika jam mencapai H+8 pukul 00.00 zona waktu site, maka website nonaktif ≤ 1 jam kemudian sementara dashboard tetap bisa membayar dan mengekspor lead. | SUB-006 | Must | TC-SUB-006 |
| AC-SUB-07 | Diberikan langganan grace dan suspended, ketika perpanjangan lunas, maka website dan editor aktif ≤ 5 menit dengan release terakhir tanpa build ulang dan isi, lead, serta domain utuh (D-04). | SUB-007 | Must | TC-SUB-007 |
| AC-SUB-08 | Diberikan website Eksklusif tidak dibayar di akun yang punya website lain, ketika H+28 dan H+30 disimulasikan, maka email peringatan terkirim, site.purge menghapus objek dan baris website itu saja, kursinya dilepas, website lain utuh, dan menjalankan ulang tidak menimbulkan galat. | SUB-008 | Must | TC-SUB-008 |
| AC-SUB-09 | Diberikan langganan aktif, ketika pelanggan berhenti dengan konfirmasi dua langkah, maka order perpanjangan terbuka dibatalkan, pengingat berhenti, dan pada H langsung suspended; Batalkan Berhenti sebelum H mengembalikan siklus normal. | SUB-009 | Must | TC-SUB-009 |
| AC-SUB-10 | Diberikan website dengan perubahan terjadwal, domain, dan tagihan terbuka, ketika halaman Langganan dibuka, maka tingkat, status, active\_until, grace\_until, retention\_until, perubahan terjadwal, tagihan terbuka, dan tanggal habis domain tampil benar. | SUB-010 | Must | TC-SUB-010 |
| AC-SUB-11 | Diberikan website Standar bulanan, ketika pelanggan menjadwalkan template Premium tahunan, maka order perpanjangan berikutnya Rp2.000.000 tanpa prorata, hanya satu perubahan terbuka, dan pembatalan sebelum tanggal berlaku mengembalikan harga lama. | SUB-011 | Must | TC-SUB-011 |
| AC-SUB-12 | Diberikan penjadwal dijalankan dua kali dalam satu jam dan satu jam dilewati, ketika putaran berikutnya berjalan, maka setiap transisi dan email terjadi tepat sekali dan ambang yang terlewat dikejar. | SUB-012 | Must | TC-SUB-012 |
| AC-SUB-13 | Diberikan perubahan terjadwal dari template Standar ke Premium, ketika perpanjangan lunas dan periode baru mulai, maka plan berubah, isi usaha, item CMS, dan blok berpadanan pindah ke template baru, blok tanpa padanan tersembunyi, release baru aktif, dan perubahan berstatus applied. | SUB-013 | Must | TC-SUB-013 |
| AC-SUB-14 | Diberikan perubahan terjadwal dengan template baru, ketika pratinjau dibuka, maka isi saat ini tampil di template baru tanpa menyimpan revisi dan daftar blok yang akan disembunyikan tampil. | SUB-014 | Should | TC-SUB-014 |
